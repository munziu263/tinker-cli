# Garden survey model

A 3D model of the garden as it stands (late November 2026), rebuilt from a 15-second
phone pan. It is the "before" picture: the base for trying out new layouts.

- `garden.json` is the garden. Every wall, building, tree and object is one entry with a
  position in metres, a size, and a note on how sure the measurement is.
- `build.py` turns that file into a Blender scene (`out/garden.blend`), a one-file
  `out/garden.glb`, and the web model the viewer loads (`viewer/model/`).
- `viewer/` is the three.js page: orbit, plan view, layer toggles, a tape measure, and a
  mode that puts the 3D camera exactly where the phone was so the model can be checked
  against the footage.

## Rebuild

```
pip install bpy numpy pillow        # Blender as a Python module (Python 3.13)
python build.py                     # about 45 s
python tools/serve.py               # preview at http://localhost:8765
```

`build.py` also runs inside Blender: `blender --background --python build.py`.
Textures are generated by code into `textures/`; nothing is downloaded. Everything the
build writes (`textures/`, `out/`, `viewer/model/`) is ignored by git, so a fresh clone
has to run `build.py` once before the viewer has anything to show.

## Changing the garden

Edit `garden.json` and run `build.py` again. Coordinates: the origin is the spot on the
lawn where the video was filmed, `+X` points at the long east wall, `+Y` up the lawn
towards the road hedge, `+Z` up. `rot` is degrees anticlockwise seen from above.
Remove an entry to remove the thing; copy one to add another. The available `type`s are
the keys of `BUILDERS` in `build.py`, and their parameters are the arguments of the
functions in `gardenkit/`.

In Blender every feature is a named object in a collection per layer (Ground, Boundaries,
Buildings, Planting, Furniture and objects, Surroundings), so things can also be moved
or hidden by hand. "Video viewpoint" is a camera placed where the pan was filmed.

## How it was measured

1. COLMAP structure-from-motion on every second frame (228 frames, 76,000 points) gave
   the phone's position and direction for each frame.
2. The lawn was fitted as a plane and the model turned so the paving runs along the axes.
3. Scale came from things of known size: brick courses, the outbuilding door, the bench,
   the bistro tables, the paving flags. They agree that the phone was about 1.96 m above
   the lawn, give or take 3%.
4. Anything touching the ground was placed by projecting its pixel onto the lawn plane;
   walls and buildings were cross-checked against the 3D points on their faces.

`tools/survey/` holds those steps: `sfm.py` (COLMAP), `align.py` (gravity, ground plane,
scale), `plan.py` and `measure.py` (pixel picks to plan coordinates), `export_frames.py`
(stills and camera poses for the viewer's compare mode).

## What is not in the repository

This repository is public, so nothing captured by the camera is committed: not the video,
not the stills the viewer fades against (`viewer/frames/`, `viewer/frames.json`), not the
survey point cloud (`tools/survey/survey.npz`). Without them the viewer simply hides
"Compare with video"; the model itself needs none of them. To bring them back from the
original video (`pip install pycolmap`, and `ffmpeg` on the path):

```
ffmpeg -i IMG_3314.mov -q:v 2 -start_number 0 frames/f_%04d.jpg
python tools/survey/sfm.py frames work 2 10                    # about 25 min on 4 cores
python tools/survey/align.py work/sparse/0 tools/survey/survey.npz 1.96
python tools/survey/export_frames.py tools/survey/survey.npz frames viewer -5.3 44
```

`1.96` is the camera height in metres that sets the scale; `-5.3` is the turn, in degrees,
that lines the plan up with the paving.

## How far to trust it

| Where | Roughly |
| --- | --- |
| Within 8 m of the viewpoint (bench, beds, patio, pale tree) | ±0.2 m |
| South wall, willow, picnic table, outbuilding, shed (10-15 m) | ±0.5 m |
| Far lawn and road hedge (20-30 m) | ±2 m or worse |
| Overall scale | ±3% |

Not in the footage at all: the stretch of the east side north of the bench, anything
behind the camera's starting direction, and the house above the eaves. Those parts are
marked `assumed` and are placeholders. Tree crowns are generic; species are not identified.

One tape measurement on site would pin the scale down properly. The model says the
patio's east edge is 6.3 m long and the picnic table 2.15 m; measure either and every
other dimension can be corrected by the same ratio.
